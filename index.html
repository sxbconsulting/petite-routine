Le calendrier est le rappel le plus fiable : il sonne même quand l'app est fermée, sur iPhone comme sur Android. Les notifications de l'app ne fonctionnent que si elle est ouverte ou récemment utilisée. Une pastille orange apparaît sur l'onglet quand l'heure est passée et la routine pas terminée. Les rappels du calendrier suivent votre semaine type, pas le mode vacances.
La sauvegarde contient tout ce qui concerne cet enfant : ses routines, ses étoiles, sa tirelire et son historique. Conservez-la ailleurs que sur ce téléphone — un mail que vous vous envoyez suffit. C'est elle qui vous protège si vous perdez à la fois l'appareil et le code famille. Restaurer remplace définitivement les données actuelles de cet enfant.
⚠️ Mode aperçu : les données ne sont pas sauvegardées ici. Une fois l'app installée sur votre téléphone, tout sera mémorisé automatiquement.
